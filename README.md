# Мебель для дома

Общая страница четырёх проектов: **Спальня, Прихожая, Постирочная, Ванная**. В каждом сохранены наполнение, фасады, размеры и предложения по хранению. Только светлая тема.

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны; страницы работают локально и на GitHub Pages. Вкладка помещения сохраняется в адресе, например `index.html#bathroom`.

## GitHub Pages

1. Загрузите содержимое этой папки в репозиторий, сохранив структуру файлов.
2. Откройте **Settings → Pages → Build and deployment**.
3. Выберите **Deploy from a branch**, свою ветку и папку **/(root)**, затем **Save**.
4. После публикации откройте адрес, который покажет GitHub.

Точка входа — `index.html`. Все ссылки на страницы и ресурсы относительные, поэтому сайт работает и по адресу проекта `https://имя.github.io/репозиторий/`. Файл `.nojekyll` отключает обработку Jekyll. [Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Файлы

- `index.html` — общая страница.
- `assets/site.css`, `assets/site.js` — оформление и вкладки.
- `wardrobe-preview.html`, `hallway-preview.html`, `laundry-preview.html`, `bathroom-preview.html` — самостоятельные интерактивные схемы. Каждую можно открыть отдельно.
- `*-concept.md`, `wardrobe-audit.md` — пояснения, расчёты, источники и условия, которые нужно проверить перед изготовлением.
- `tools/prepare-previews.py` и `assets/preview.js` — подготовка новых экспортов схем для общей страницы.

После замены схемы новым экспортом выполните `python tools/prepare-previews.py`. Скрипт уберёт внешнюю оболочку экспорта, сохранит светлую тему и добавит автоматическую подстройку высоты. Повторный запуск безопасен. Для уже подготовленных файлов запускать его не требуется.

Папка `tmp/` содержит рабочие материалы проверки и исключена из Git. Для публикации она не нужна.

Все проекты остаются концептами. Монтажные зазоры, крепления, фурнитуру и оборудование проверяют по фактическому замеру и выбранным изделиям; условия перечислены в самих проектах.
